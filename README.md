# Achieve Your Goals

A desktop app for one person that organises work around goals. Each goal states up front what proof will show it is done, tasks are the next actions, and a built-in pomodoro timer tracks the time spent on them. All data stays on your device.

This repository holds only the releases. The source code is kept elsewhere.

## Download

Get the latest version from the [Releases page](https://github.com/JeanKouss/achieve-your-goals-releases/releases/latest):

- **Windows:** the `*-setup.exe` installer. Windows SmartScreen may warn on the first install because the app is not code-signed: choose **More info**, then **Run anyway**.
- **Linux:** the `.AppImage` file. Make it executable (`chmod +x`) and run it.

Once installed, the app updates itself. Every update is signed, and the app refuses any update whose signature does not match.
